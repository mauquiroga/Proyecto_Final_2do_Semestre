Nuestro programa es un pequeño software desarrollado para la administración de una tienda que vende productos como ser abarrotes refrescos y dulces 
Donde nuestro enfoque se encuentra en la gestión de los usuarios y en especial de los productos de la tienda 
Iniciamos el código desde la pestaña main que sería nuestra rama principal donde tenemos alojadas las funciones del inicio del sistema el cual esta modularizado
para iniciar sesión tenemos dos opciones ingresar con el administrador o usuario 
una vez inicia el sistema con un username y password podremos accesar a distinta opciones dependiendo del nivel de acceso elegido 
el sistema recurrirá al llamado de distintas funciones que se encuentran alojadas en otros módulos como ser Administrador, Carrito, Datos, Inventario, Login, Usuario, Validaciones. 
Modulo Administrador.
En este apartado encontraremos funciones como:
Lista de usuarios: donde podremos ver la cantidad de usuarios registrados y datos como usename nombre y edad
También podremos realizar modificaciones a dichos usuarios como realizar cambios de nombre edad username y contraseña podremos agregar o eliminar usuarios el sistema también a recibido correcciones como el detectar si un usuario ya existe para no entrar en conflicto en caso de que se repitan los datos 
En esta misma modulo también se hayan alojadas funciones como modificar datos de la tienda 
Como modificar código, precio, stock, nombre.
Modulo Usuario.
Acá tenemos las funciones de acceso exclusiva de los usuarios o vendedor donde se ha limitado su acceso o funciones exclusivamente a venta de productos y la verificación de datos de otros usuarios mas no la modificación de los mismos
También encontraremos funciones del carrito de compras donde tendremos acceso al menú stock de la tienda donde podremos realizar la compra de productos 
Modulo Login.
En este apartado encontramos las funciones las funciones de inicio de sesión que se encuentran directamente relacionada con la modulo main y modulo datos
Modulo Datos.
En esta parte se encuentran alojados los datos de inicio de sesión tanto del administrador como de los usuarios y donde también se alojará los datos de nuevos usuarios
Esta modulo también va relacionada con los módulos main administrador usuario y login 
Modulo Carrito:
En este aparto tenemos funciones de gestión de la tienda como ser ver el catálogo agregarlo a un carrito de compras donde podremos adicionar distintos productos del catálogo.
En este apartado el administrados tiene un acceso de mayor nivel donde podrá gestionar opciones como agregar, eliminar, reabastecer y eliminar los productos.
Modulo Inventario.
Acá hemos alojado las listas que contienen la información del inventario de la tienda como ser cantidad precio y nombre del producto y todas ellas son modificables.
